# Аудит базовой версии AssetForge Studio v0.8.1

## Источник

- Архив: `AssetForgeStudio_v0.8.1_STABLE_BASELINE.zip`
- SHA-256: `DFCF46742A659575367343C1FDC09F9AD367EE6A7ACE62F1EB4CE3CD9CDF6057`
- Исходная структура: 139 ZIP-записей
- Локальная рабочая папка: `D:\unity1\AssetForgeStudio`

## Результат аудита

База представляет собой Python/Tkinter-приложение с модульным UI, Blender Bridge,
Unity Bridge, `.afs`-проектами, Job Queue, Event Bus, SQLite Asset Database и 39
автоматическими тестами. Архив содержит один GLB-файл размером около 49 МБ.

В архив также попали каталоги `__pycache__`; они не включаются в Git благодаря
существующему `.gitignore`.

## Выявленный дефект

Исходный архив не освобождал SQLite-соединения после транзакций. На Windows это
блокировало временный файл базы и приводило к ошибке одного теста. Исходное состояние
зафиксировано коммитом `13379b1` и тегом `studio-v0.8.1-baseline`.

Исправление оформлено отдельно как v0.8.1.1 Hotfix без изменения схемы SQLite или
публичного API. После исправления все 39 тестов проходят на Python 3.12 и 3.14.

## Архитектурное решение

AI Center добавляется отдельным модулем. Frozen Core не используется для хранения
ключей и не получает зависимости от конкретного AI-провайдера.
