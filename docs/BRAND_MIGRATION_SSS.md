# Sprite Station Studio: переход с AssetForge Studio

## Новое имя

- Полное название: **Sprite Station Studio**.
- Сокращение: **SSS**.
- Репозиторий: `Barbudo23/SpriteStationStudio`.
- Рабочая папка: `D:\unity1\SpriteStationStudio`.
- Назначение продукта не изменилось: создание статических и анимированных 2D-спрайтов из 3D-моделей с управляемым ракурсом камеры.

Новое имя отделяет приложение от прежнего проекта AssetForge и предотвращает смешивание новых пользовательских данных.

## Новые пути

| Назначение | Новый путь | Совместимость |
|---|---|---|
| Настройки пользователя | `~/.sprite_station_studio` | чтение старых настроек из `~/.assetforge`, если новых ещё нет |
| Импорт в Unity | `Assets/SpriteStationImports` | `Assets/AssetForgeImports` по-прежнему принимается |
| Рабочий ассет Unity | `Assets/SpriteStationInput` | старые проекты не переносятся автоматически |

Сохранение настроек выполняется только в новый каталог. Кэш библиотеки Unity создаётся заново в новом каталоге и не разделяется с AssetForge.

## Сохранённые контракты

Для безопасного открытия существующих проектов в этой версии намеренно сохранены:

- расширение проекта `.afs`;
- Python-классы `AssetForgeCore`, `AssetForgeProject` и `AssetForgeApp` как внутренние API;
- Unity entry point `AssetForgeUnityBridge.Execute` и аргумент `-assetForgeCommand`;
- чтение старого каталога настроек и старой папки импорта Unity.

Это совместимые устаревшие идентификаторы, а не текущее название продукта. Их переименование потребовало бы отдельной миграции формата и Unity-автоматизации.

## История проекта

Старые release notes, baseline-аудиты и записи changelog сохраняют название AssetForge Studio как исторический факт. Они не определяют текущее имя приложения.
