# AI Center v0.8.2 Dev

AI Center — изолированный модуль генерации изображений для AssetForge Studio.

## Провайдеры

1. `openai` — официальный OpenAI Images API.
2. `codex` — локальный Codex Bridge: создаёт проверяемое задание без API-ключа.
3. `closeai` — OpenAI-совместимый CloseAI API.

Провайдер по умолчанию — `codex`.

## Безопасность

- API-ключи не сохраняются в проекте и `~/.assetforge/ai_center.json`.
- OpenAI использует переменную окружения `OPENAI_API_KEY`.
- CloseAI использует переменную окружения `CLOSEAI_API_KEY`.
- Ошибки API очищаются от значения ключа перед отображением.
- Любое изображение получает статус `REVIEW_REQUIRED`.
- Codex-задание получает статус `AWAITING_CODEX`.
- Автоматическое утверждение или продвижение производственного этапа запрещено.

## Запуск

1. Запустите `run_windows.bat` или `python run.py`.
2. В левой панели выберите **AI Center**.
3. Выберите провайдер.
4. Введите prompt и добавьте от одного до четырёх референсов.
5. Укажите каталог результата и Camera ID.
6. Нажмите **PREPARE / GENERATE**.

Для API-провайдеров установите дополнительную зависимость:

```powershell
python -m pip install ".[ai]"
```

Codex Bridge не требует пакета `openai` и не выполняет платный запрос: он сохраняет
JSON-задание, которое затем обрабатывается встроенным генератором Codex.

## Формат задания

Файл `<CAMERA>_ai_job.json` содержит provider, prompt, SHA-256 prompt, абсолютные пути
референсов, путь результата, request ID (если доступен) и обязательный review gate.
Ключи в файл не записываются.

## Ограничения Dev

- API-запрос запускается синхронно из окна AI Center.
- Пакетная очередь ограничена тремя изображениями, но автоматический batch UI ещё не
  реализован.
- Импорт утверждённого результата в Blender/Unity pipeline — следующий этап.
