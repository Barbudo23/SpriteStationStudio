# AssetForge Studio v0.8.1 Stable Baseline

Дата фиксации: текущая сессия разработки.

## Основа

Сборка основана на `v0.8.1 Core Hotfix`.

## Подтверждено автоматически

- Python compilation;
- полный набор unit tests;
- регрессионная проверка Tkinter geometry managers.

## Подтверждено пользователем

- ошибка запуска v0.8.0 обнаружена на Windows;
- исправление подготовлено в v0.8.1.

## Требует пользовательской проверки

- запуск v0.8.1 на Windows;
- реальный Blender render;
- реальный Unity Bridge;
- анимационный рендер FBX/GLB.

## Статус

Это базовая стабильная точка для дальнейшей ZIP-разработки.
Рабочие компоненты не должны изменяться без отдельного Hotfix.
